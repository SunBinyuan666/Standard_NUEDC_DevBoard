# SG90 舵机按键控制工程要求

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0.0 |
| 日期 | 2026-10-20 |
| 状态 | 新建 STM32CubeMX 工程的基线需求 |
| 目标硬件 | Standard NUEDC DevBoard，STM32F103VET6 |
| 目标外设 | 1 路 SG90 舵机、3 个用户按键、3 个板载 LED |

---

## 1. 目的

定义一个独立的新 STM32CubeMX 工程，使用开发板上的三个用户按键调整 SG90 舵机的目标姿态，并通过板载 LED 指示当前调节模式及系统运行状态。该文档作为 CubeMX 配置、固件实现和验收测试的依据。

本文所称“精准控制”指目标角度和舵机控制脉宽具有可重复、可调整的设定；不代表 SG90 能在无位置反馈条件下保证实际轴角达到同等精度。

## 2. 范围与假设

### 2.1 工程范围

- 使用 STM32F103VET6 和 STM32 HAL。
- 使用 TIM3_CH1 在 PA6 输出舵机控制 PWM。
- 使用 PE13、PE14、PE15 读取三个板载用户按键。
- 使用 PB6、PB7、PD8 驱动板载 LED。
- 目标角度范围、舵机脉宽边界和按键步进应由具名常量管理，便于后续校准。

### 2.2 不在本版范围内

- 不读取舵机轴的实际位置；本方案没有外部编码器或舵机反馈输入。
- 不实现多舵机、无线遥控、串口命令、自动轨迹规划或闭环 PID。
- 不假定每只 SG90 的机械端点、脉宽行程和实际角度完全相同。

## 3. 硬件接口与引脚分配

引脚根据 Standard NUEDC DevBoard 原理图/连接资料确认。GPIO 扩展排针与板载器件可能共用网络，应用必须考虑板载负载。

| 功能 | 开发板器件 | MCU 引脚 | 电气/配置要求 |
|---|---|---|---|
| 舵机 PWM | H2.30 | PA6 / TIM3_CH1 | 定时器复用输出，默认 TIM3 引脚映射；不启用 TIM3 重映射 |
| 角度减小键 | SW2 | PE13 | 按下接 GND，低电平有效；输入上拉 |
| 角度增大键 | SW3 | PE14 | 按下接 GND，低电平有效；输入上拉 |
| 步进模式键 | SW4 | PE15 | 按下接 GND，低电平有效；输入上拉 |
| 细调状态灯 | LED3 | PB6 | 低电平点亮，高电平熄灭 |
| 粗调状态灯 | LED4 | PB7 | 低电平点亮，高电平熄灭 |
| 系统心跳灯 | LED5 | PD8 | 低电平点亮，高电平熄灭 |

SW2/SW3/SW4 信号上分别有到地电容，原理图没有给这些按键配置外部上拉，因此固件必须启用 MCU 内部上拉并执行软件消抖。LED 由 3.3 V 经板载限流电阻供电，MCU GPIO 拉低时点亮。

### 3.1 舵机接线要求

- 舵机红线：接稳定的外部 5 V 电源。
- 舵机棕/黑线：接电源 GND，并与开发板 GND 共地。
- 舵机黄/橙信号线：接 PA6。
- 不得从 MCU 的 3.3 V 输出或 GPIO 引脚给舵机供电。
- 不得未经供电路径核查就把舵机外部 5 V 并入开发板 5 V 网络。开发板资料提示多个 USB/5 V 来源可能存在合路关系；优先采用单独舵机电源，只共地。
- PA6 输出为 3.3 V 逻辑。接线或舵机型号改变时，应确认舵机信号输入可识别 3.3 V 高电平；不得把 5 V 信号接入 STM32 输入脚。

## 4. 用户操作定义

### 4.1 按键功能

| 按键 | 一次有效按下的动作 |
|---|---|
| SW2 / PE13 | 将目标角度减小当前步进值 |
| SW3 / PE14 | 将目标角度增加当前步进值 |
| SW4 / PE15 | 在细调和粗调模式间切换 |

- 上电默认目标角度为 90°，默认进入细调模式。
- 细调步进为 1°；粗调步进为 5°。
- 目标角度必须限制在 0° 至 180°，到达边界后饱和，不允许回绕。
- 一次稳定按下只触发一次动作；必须先释放再触发下一次。长按连发不属于本版必需功能。
- 如 SW2 与 SW3 同时按下，不改变角度；多键同时按下时应避免产生不确定的角度命令。
- 每次有效角度变化后立即更新 PWM 比较值；不应为改变 PWM 而在主循环中生成软件延时波形。

### 4.2 LED 状态定义

| LED | 点亮条件 | 熄灭条件 |
|---|---|---|
| LED3 / PB6 | 当前为细调模式（1°/步） | 当前为粗调模式 |
| LED4 / PB7 | 当前为粗调模式（5°/步） | 当前为细调模式 |
| LED5 / PD8 | 以约 500 ms 间隔翻转，表示主循环仍在运行 | 初始化阶段可先保持熄灭 |

细调和粗调指示灯应互斥，不允许两灯同时常亮。由于 LED 为低电平点亮，GPIO 写低代表亮，写高代表灭。

## 5. STM32CubeMX 配置要求

### 5.1 工程和器件

1. 新建工程并选择 `STM32F103VETx`（对应实际芯片 STM32F103VET6）。
2. 固件包选择可用的 STM32Cube FW_F1 版本；已有同板 CubeMX 工程使用过 STM32Cube FW_F1 V1.8.7。
3. Project Manager 中选择实际使用的 IDE/工具链，例如 STM32CubeIDE 或 MDK-ARM；不得把工具链选择与目标 IDE 混用。

### 5.2 RCC 与时钟树

开发板有 8 MHz 无源高速晶体 X1，因此要求：

- RCC：HSE 设为 `Crystal/Ceramic Resonator`，不是 `Bypass Clock Source`。
- PLL 输入选择 HSE，PLL 倍频设为 ×9。
- SYSCLK/HCLK 配置为 72 MHz。
- AHB 分频为 /1。
- APB1 分频为 /2，PCLK1 为 36 MHz。
- APB2 分频为 /1，PCLK2 为 72 MHz。
- 确认 CubeMX 时钟树中的 TIM3 clock 为 72 MHz。STM32F1 在 APB 预分频不为 1 时，APB 定时器时钟为 APB 时钟的 2 倍。

### 5.3 TIM3 PWM

在 `Timers -> TIM3` 中配置：

| 项目 | 要求值 | 说明 |
|---|---:|---|
| Clock Source | Internal Clock | 使用内部定时器时钟 |
| Channel 1 | PWM Generation CH1 | 使用 PA6 / TIM3_CH1 |
| Prescaler | 71 | 72 MHz / (71 + 1) = 1 MHz，即 1 μs/tick |
| Counter Period / ARR | 19999 | (19999 + 1) μs = 20 ms |
| Pulse / CCR1 | 1500 | 上电中位命令，约 1.5 ms 高电平 |
| Counter Mode | Up | 向上计数 |
| PWM Mode | PWM mode 1 | 高电平有效脉冲 |
| Polarity | High | 高电平脉宽编码目标位置 |
| Clock Division | DIV1 | 不额外分频 |
| Fast Mode | Disable | 普通输出比较 |

计算关系：

```text
计数频率 = TIM3_CLK / (PSC + 1)
         = 72,000,000 / 72
         = 1,000,000 Hz

PWM频率 = 计数频率 / (ARR + 1)
        = 1,000,000 / 20,000
        = 50 Hz

高电平脉宽 = CCR1 × 1 μs
```

ARR 是计数器自动重装载值，因此周期 20,000 个计数对应 ARR=19,999，不是 20,000。TIM3 不需要启用 Update、Capture/Compare 中断或 DMA；PWM 由定时器硬件持续输出。

### 5.4 GPIO 输入与输出

**按键 PE13/PE14/PE15：**

- Mode：`GPIO_Input`。
- Pull：`Pull-up`。
- 不配置为 EXTI；本版采用主循环轮询和软件消抖。
- 输入低电平表示按下，高电平表示释放。

**LED PB6/PB7/PD8：**

- Mode：`GPIO_Output`。
- Output type：`Push-Pull`。
- Pull：`No pull-up and no pull-down`。
- Speed：`Low`。
- Initial output level：`High`，保证初始化阶段 LED 默认熄灭。

### 5.5 NVIC 与代码生成

- 不启用 TIM3 NVIC 中断。
- 不启用 EXTI13/14/15 中断；SysTick 由 HAL 用于毫秒时间基准。
- 代码生成后通过 `HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1)` 启动 PWM 一次，之后通过更新 TIM3_CH1 比较值改变脉宽。
- CubeMX 生成文件应尽量保持自动生成内容；应用逻辑放在独立应用模块或 `USER CODE` 区域，避免重新生成时被覆盖。

## 6. 固件行为要求

### 6.1 初始化和默认状态

系统启动顺序至少包括：

1. `HAL_Init()` 和系统时钟初始化。
2. 初始化 GPIO 与 TIM3。
3. 初始化目标角度为 90°、模式为细调。
4. 启动 TIM3_CH1 PWM，并设置约 1500 μs 初始脉宽。
5. 设置 LED3 亮、LED4 灭；LED5 由心跳任务定时翻转。
6. 进入持续运行的主循环。

### 6.2 脉宽与角度换算

- 初始验证使用保守脉宽范围：1000–2000 μs；这不是对每一只 SG90 的机械极限保证。
- 通过常量 `SERVO_MIN_PULSE_US` 和 `SERVO_MAX_PULSE_US` 管理脉宽边界，并支持逐步校准。
- 线性初始换算公式：

```text
pulse_us = min_pulse_us
         + round(angle_deg × (max_pulse_us - min_pulse_us) / 180)
```

- 在当前 1 μs/tick 配置下，比较值的单位为微秒计数值，脉宽更新可使用 `__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, pulse_us)`。
- 目标角度必须先限幅再换算，禁止因无符号整数下溢而产生超范围比较值。
- 比较值仅在目标角度改变时更新；不得通过忙等循环或软件翻转 GPIO 产生舵机 PWM。

### 6.3 消抖和非阻塞处理

- 按键状态应连续稳定至少 20 ms 才确认按下或释放。
- 一次稳定按下仅产生一次按键事件；按住不放不重复调整。
- 使用 `HAL_GetTick()` 或等效毫秒节拍进行消抖和 LED 心跳；禁止在按键处理或主循环中使用长时间阻塞延时。
- 按键扫描、LED 更新与状态处理不得停止 TIM3 硬件 PWM 输出。

### 6.4 建议的软件模块

可按以下职责拆分，不强制固定目录名：

- `app_servo.c/.h`：目标角度限幅、脉宽换算、PWM 更新。
- `app_button.c/.h`：按键状态读取、消抖、单次事件生成。
- `app_led.c/.h`：细调/粗调指示和心跳灯。
- `main.c`：初始化模块并在主循环中调用非阻塞处理函数。

应用代码应使用明确的固定宽度整数类型和具名常量；函数、变量命名及文件结构遵循 `个人编程代码规范.md`。HAL 生成文件与应用层职责保持清晰。

## 7. 电气与机械安全要求

- 调试前先固定舵机本体，卸下可能造成夹伤或碰撞的连杆/负载，从中位小幅测试。
- 首次上电只发送 1500 μs 中位脉冲；确认方向与供电正常后，再逐步扩展脉宽范围。
- 若舵机在端点持续嗡鸣、发热、抖动或堵转，应立即断电并缩小脉宽边界，不得长时间顶住机械止点。
- 外部 5 V 电源能力应满足舵机启动和堵转瞬态电流需求；电源规格按实际 SG90 型号和负载核实，不以 MCU 稳压输出代替舵机电源。
- 电源地必须共地；尽量缩短舵机电源和信号回路，避免舵机电流造成 MCU 复位或 PWM 异常。
- 上电、复位期间 PWM 初始化前，舵机可能没有有效定位命令；结构设计应允许该短暂状态。

## 8. 验证计划

| 编号 | 验证内容 | 方法与通过条件 |
|---|---|---|
| VT-01 | 工程配置 | CubeMX 工程选择 F103VETx，时钟树显示 SYSCLK 72 MHz、TIM3 时钟 72 MHz |
| VT-02 | PWM 基本波形 | 示波器/逻辑分析仪测 PA6，周期约 20 ms，频率约 50 Hz |
| VT-03 | 初始中位脉冲 | 上电后 PA6 高电平约 1500 μs，舵机无明显持续堵转 |
| VT-04 | PWM 可调 | 更新 CCR 后，高电平按微秒计数变化；主循环无阻塞生成波形 |
| VT-05 | 按键减小 | 每次 SW2 有效按下只减小一个当前步进值 |
| VT-06 | 按键增大 | 每次 SW3 有效按下只增大一个当前步进值 |
| VT-07 | 模式切换 | 每次 SW4 有效按下切换 1°/5°，LED3/LED4 对应且互斥 |
| VT-08 | 按键消抖 | 单次按压不重复触发；释放后可再次触发 |
| VT-09 | 角度边界 | 目标角度不低于 0°、不高于 180°，到边界不回绕 |
| VT-10 | 心跳灯 | LED5 以约 500 ms 间隔翻转，按键操作期间仍继续 |
| VT-11 | 供电与复位 | 舵机动作时 MCU 不异常复位；舵机电源与逻辑地连接正确 |
| VT-12 | 机械端点 | 在无负载条件下逐步校准 min/max 脉宽，无持续嗡鸣、卡滞或异常发热 |

## 9. 验收标准

工程满足以下全部条件时视为本版需求通过：

1. CubeMX 工程与 STM32F103VET6 对应，生成代码可在选定工具链下编译。
2. PA6 输出 50 Hz 硬件 PWM，定时器配置为 1 μs 计数分辨率。
3. 上电默认命令为 90°/约 1500 μs，角度命令保持在 0–180°。
4. SW2、SW3 可按当前细调/粗调步进改变目标角度，SW4 可切换两种步进模式。
5. LED3、LED4 能互斥表示调节模式，LED5 能指示程序运行。
6. 按键消抖有效，PWM 输出不依赖主循环忙等。
7. 舵机使用适当的外部 5 V 供电并与 MCU 共地；端点脉宽已在实物上安全校准。
8. 文档、代码常量和实测脉宽范围一致；若更换舵机或机械结构，重新执行端点校准。

## 10. 已知限制

- SG90 的 PWM 输入是位置命令，不提供 MCU 可直接读取的实际轴角反馈；无法仅凭本工程证明实际角度等于指令角度。
- 1000–2000 μs 和 0–180° 是便于起步的线性标称映射，真实零位、方向、端点和每度响应需实物测量。
- 若验收指标要求小于特定角度误差，应先定义测量方法和误差限值，并增加外部角度传感器或选择带反馈执行器。

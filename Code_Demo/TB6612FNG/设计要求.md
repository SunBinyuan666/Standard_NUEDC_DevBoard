# TB6612FNG 双直流电机功能测试——设计要求

## 1. 文档定位

- **任务来源**：当前需求是“在 Standard NUEDC DevBoard 上外接 TB6612FNG，驱动电赛小车的两个直流电机，先完成双电机功能测试”。本文据此形成软件实现的输入要求，不是对既有需求文档的转录。
- **控制对象**：TB6612FNG 双 H 桥驱动模块/电路，A、B 两路各接一台有刷直流电机。
- **当前阶段目标**：实现双电机独立启停、正反转和 PWM 调速，验证接线、方向与安全停机；暂不实现编码器测速、PID、循迹或整车闭环控制。
- **固件基础**：STM32F103VET6、STM32CubeMX、STM32Cube HAL、72 MHz 系统时钟；保持 SWD 下载调试可用。
- **文档性质**：以下 MCU 引脚是依据当前开发板连接报告作出的本任务固定分配，不改动既有硬件；上电前仍须核对实际 TB6612FNG 模块丝印、电机参数和供电条件。

## 2. 已确认事实与待确认条件

### 2.1 已确认的开发板事实

依据 `outputs/所有元器件的连接方式.md`：

1. 主控为 **STM32F103VET6，LQFP-100**，GPIO 逻辑电平为 3.3 V。
2. PA6、PA7 分别只连接到 H2.30、H2.29，可作为 TIM3_CH1、TIM3_CH2 的默认无重映射 PWM 输出。
3. PE8、PE9、PE10、PE11、PE12 分别连接到 H2.38、H2.37、H2.40、H2.39、H2.42，未与已记录的板载外设共网。
4. H2.2/4/6/8 为板级 3.3 V，H2.9/10/11/12 为 GND。
5. 现有 PWM_LED 示例使用 TIM4 的 PB6/PB8；本任务不复用该应用层测试逻辑，也不占用 PB6/PB8。

### 2.2 实施前必须补齐的硬件信息

- TB6612FNG 是成品模块还是自制电路，以及端子丝印和模块已有上下拉、去耦配置。
- 电机额定电压、空载电流和堵转电流；电池类型、标称/满电电压及持续放电能力。
- A/B 两路分别对应车体左侧还是右侧。本文暂定 **A=左电机、B=右电机**。
- 若电机堵转电流、电源能力或模块散热条件不满足 TB6612FNG 的限制，不得直接上车堵转测试，应更换驱动方案或降低测试条件。

## 3. 总体电气方案

```text
独立电机电源（电压按电机选择）
  ├─ 电源正极 → TB6612FNG VM
  └─ 电源负极 → TB6612FNG GND ─┐
                               ├─ 与开发板 GND 单点可靠共地
开发板 3.3 V → TB6612FNG VCC   ┘

STM32 TIM3_CH1/CH2 → PWMA/PWMB
STM32 PE8～PE11    → AIN1/AIN2/BIN1/BIN2
STM32 PE12         → STBY
TB6612FNG AO1/AO2  → 左电机
TB6612FNG BO1/BO2  → 右电机
```

### 3.1 电源硬性要求

1. **VM 必须接独立电机电源，禁止从开发板 H2 的 5 V/3.3 V 排针取电驱动电机。** 开发板逻辑电源和电机电源只共 GND，不把 VM 与 VCC 短接。
2. TB6612FNG 芯片数据表推荐工作范围：VM 为 2.5～13.5 V，VCC 为 2.7～5.5 V。本设计固定使用 **VCC=3.3 V**；VM 按电机额定电压和电池满电电压共同核定，且不得超过模块/芯片允许范围。
3. 数据表给出的每通道平均输出电流 1.2 A、峰值 3.2 A 属于极限参数，不等于任何散热条件下都能长期输出。选型必须核查堵转电流、持续电流、模块铜箔与温升，禁止把 3.2 A 当作持续额定值。
4. 在驱动板 VM-GND 入口就近配置 **100 µF 电解电容 + 100 nF 陶瓷电容**；若裸芯片或模块没有 VCC 去耦，在 VCC-GND 就近增加 100 nF。电容耐压应高于电源满电电压并留有余量。
5. 电机线和电源线应短、粗并尽量双绞；大电流回路不要绕行开发板。可在每个电机端子就近并联 100 nF 陶瓷电容抑制干扰，但不得以此替代合理布线和共地。
6. STBY 外部建议用 10 kΩ 下拉至 GND，保证 MCU 复位或高阻期间驱动器待机。若成品模块已有上拉/下拉，先核对原理图或实测默认状态，确保最终默认安全，不得让上下拉形成不确定分压。

## 4. 接线与引脚分配

### 4.1 MCU 到 TB6612FNG 信号接线

| 功能约定 | TB6612FNG 端子 | MCU 引脚 | MCU 物理脚 | 开发板排针 | CubeMX 配置 |
|---|---|---:|---:|---:|---|
| 左电机 PWM | PWMA | PA6 / TIM3_CH1 | 31 | H2.30 | TIM3_CH1 PWM Generation，无重映射 |
| 右电机 PWM | PWMB | PA7 / TIM3_CH2 | 32 | H2.29 | TIM3_CH2 PWM Generation，无重映射 |
| 左电机方向 1 | AIN1 | PE8 | 39 | H2.38 | GPIO_Output，推挽 |
| 左电机方向 2 | AIN2 | PE9 | 40 | H2.37 | GPIO_Output，推挽 |
| 右电机方向 1 | BIN1 | PE10 | 41 | H2.40 | GPIO_Output，推挽 |
| 右电机方向 2 | BIN2 | PE11 | 42 | H2.39 | GPIO_Output，推挽 |
| 双通道总使能/待机 | STBY | PE12 | 43 | H2.42 | GPIO_Output，推挽，初始低电平 |

**排针号仅按当前原理图/网表报告给出，实物接线前仍须用板卡丝印和万用表确认，不能根据排针外观左右位置猜针号。**

### 4.2 电源、地和电机接线

| TB6612FNG 端子 | 连接对象 | 要求 |
|---|---|---|
| VCC | 开发板 H2.2（3.3 V） | 仅逻辑供电；禁止接 VM 或更高电压 |
| GND | 开发板 H2.10（GND）以及电机电源负极 | 必须共地；大电流回流直接在驱动板侧闭合 |
| VM | 独立电机电源正极 | 电压按电机确定；禁止接开发板 5 V 排针作为电机供电 |
| AO1、AO2 | 左直流电机两个端子 | 两线互换只改变转向，软件最终统一方向定义 |
| BO1、BO2 | 右直流电机两个端子 | 两线互换只改变转向，软件最终统一方向定义 |
| STBY | PE12，另有安全下拉 | 低电平时两路输出高阻；正常运行时才置高 |

### 4.3 控制逻辑约定

STBY=高时，两路分别遵循以下逻辑；PWM 为有效高电平占空比控制：

| IN1 | IN2 | PWM | 功能 |
|---:|---:|---:|---|
| 1 | 0 | PWM 调速 | 一个方向旋转 |
| 0 | 1 | PWM 调速 | 反方向旋转 |
| 1 | 1 | 1 | 短路制动 |
| 0 | 0 | 1 | 停止/输出高阻（滑行） |
| 任意 | 任意 | 0 | 短路制动 |
| 任意 | 任意，STBY=0 | 任意 | 待机，两路输出高阻 |

软件应把“方向正负”和“车体实际前后”解耦。若某侧实际前进方向相反，只修改该电机的 `REVERSED` 配置，不在业务代码中散落电平补丁。

## 5. CubeMX 与外设配置要求

1. 时钟保持现有 HSE=8 MHz、PLL×9、SYSCLK=72 MHz；APB1 定时器时钟为 72 MHz。
2. 启用 TIM3 内部时钟，**不启用 TIM3 重映射**，CH1=PA6、CH2=PA7，两路均为 PWM Generation。
3. 双路 PWM 共用频率，初始设为 **20 kHz**：`PSC=0`、`ARR=3599`、`Pulse(CH1)=0`、`Pulse(CH2)=0`。计数周期为 3600，占空比按 `CCR=0～3600` 映射；不得照搬 PWM_LED 示例的 1 kHz/ARR=999 参数。
4. PWM 模式使用 PWM1、高电平有效；初始化完成后两路 CCR 必须为 0，再启动 PWM 通道，并检查 HAL 返回值。
5. PE8～PE12 配置为推挽输出、无内部上下拉（STBY 的外部安全下拉仍保留），初始输出低电平；速度档位满足 GPIO 翻转即可，无需复用功能。
6. 保持 PA13/PA14 为 SWD。不得占用 PB2/BOOT1、板载串口、USB、SPI 和按键引脚。
7. CubeMX 再生成时只保留用户区代码；`Motor_*` 与 `MotorTest_*` 文件不得被生成过程覆盖。

## 6. 软件代码架构要求

### 6.1 分层与文件边界

```text
Core/
├─ Inc/
│  ├─ main.h                  CubeMX 引脚宏或集中引脚定义
│  ├─ motor_tb6612.h          双电机驱动公开接口
│  └─ motor_test.h            功能测试状态机接口
└─ Src/
   ├─ main.c                  外设初始化、Motor_Init、周期调度
   ├─ motor_tb6612.c          引脚/PWM操作、方向与限幅、安全停机
   └─ motor_test.c            非阻塞测试流程，不包含底层电平细节
```

- **驱动层 `motor_tb6612`**：只负责 TB6612FNG 和 MCU 外设，不知道小车测试步骤。
- **测试层 `motor_test`**：只调用驱动公开接口，不直接操作 GPIO、CCR 或 `htim3`。
- **应用入口 `main.c`**：完成 HAL/时钟/GPIO/TIM3 初始化后初始化驱动，主循环按 `HAL_GetTick()` 调度测试；不得在多个位置重复启动 PWM。
- 后续增加编码器/PID 时另建模块，不把测速和控制算法塞进本次驱动或测试状态机。

### 6.2 驱动公开接口要求

建议固定为以下语义，函数名可保持直接使用：

```c
void Motor_Init(void);                              /* 安全初态并启动双路PWM */
void Motor_Enable(bool enable);                     /* 双通道STBY总使能 */
void Motor_SetSpeed(MotorId_t id, int16_t speed);   /* -1000～+1000，千分比 */
void Motor_Stop(MotorId_t id);                      /* 单路占空比0，短路制动 */
void Motor_StopAll(void);                           /* 双路占空比0并拉低STBY */
```

实现约束：

1. `speed>0` 为车体前进，`speed<0` 为后退，0 为停止；超出范围先限幅，不允许有符号数溢出后进入 CCR。
2. 每路保存 `in1/in2` 引脚、TIM 通道和方向反转配置；A/B 使用同一套逻辑，禁止复制两份容易漂移的电平代码。
3. `Motor_Init` 的先后顺序固定为：**STBY=0 → 两路 CCR=0 → 方向脚安全初态 → 启动两个 PWM 通道并检查错误 → 保持待机**。初始化不得自动转电机。
4. `Motor_SetSpeed` 只允许在 STBY 已使能后输出非零占空比；0 速必须写 CCR=0。反向时先令该路 CCR=0，再切方向，测试流程保留短暂停止段，避免满占空比直接反接。
5. `Motor_Enable(false)` 必须同时清零两路 CCR 并拉低 STBY，防止重新使能时恢复旧占空比；`Motor_Enable(true)` 只解除待机，不得自动恢复非零速度。
6. `Motor_StopAll` 必须可被任何测试错误分支调用；进入 `Error_Handler` 前先尽力将 CCR=0、STBY=0，不能只停留在死循环而保持电机输出。
7. 运行中不使用 `HAL_Delay()` 串起测试步骤，采用状态机，确保停止命令和后续控制能及时执行。

### 6.3 上电与运行安全状态

- MCU 复位、下载、调试暂停和初始化期间，依靠 STBY 下拉保证输出关闭。
- 测试默认不自动连续循环；建议由 PE13/SW2 触发开始，或上电延时后只执行一次。若使用按键，应另配内部上拉和消抖，不与电机方向 GPIO 混用。
- 任一 PWM 启动失败、参数非法或测试异常时，执行 `Motor_StopAll()`。
- 首版不加入看门狗、编码器和 PID；后续上车闭环前再增加控制超时、通信失联停机等机制。

## 7. 功能测试流程要求

测试前架空车轮，先不装车轮或让驱动轮离地；首次通电使用低占空比，人员不要接触传动结构。

| 步骤 | 左电机 A | 右电机 B | 建议时间 | 检查点 |
|---|---|---|---:|---|
| 0 | 待机、0% | 待机、0% | 1 s | 上电和初始化不得转动 |
| 1 | 前进 +20% | 停止 | 2 s | A 独立运行，方向正确 |
| 2 | 停止 | 停止 | 0.5 s | A 能制动 |
| 3 | 后退 -20% | 停止 | 2 s | A 反向正常 |
| 4 | 停止 | 停止 | 0.5 s | 无异常抖动 |
| 5 | 停止 | 前进 +20% | 2 s | B 独立运行，方向正确 |
| 6 | 停止 | 停止 | 0.5 s | B 能制动 |
| 7 | 停止 | 后退 -20% | 2 s | B 反向正常 |
| 8 | 停止 | 停止 | 0.5 s | 双路均停止 |
| 9 | 前进 +20%→+50% | 前进 +20%→+50% | 各 2 s | 双路同步及调速有效 |
| 10 | `Motor_StopAll` | `Motor_StopAll` | 保持 | STBY=0，测试只执行一次 |

测试百分比是上限而非必须带载达到的转速。若 20% 下电机不能平稳启动，先检查供电和机械负载，再决定是否提高起始占空比；不得长时间堵转。

## 8. 验收标准

1. 接线与第 4 节一致，VCC=3.3 V、VM 与电机额定值匹配、开发板与驱动板可靠共地；VM 未从开发板 5 V 排针取电。
2. 复位、烧录和初始化阶段两个电机均不意外启动；STBY 默认低。
3. TIM3_CH1/CH2 实测为 20 kHz，0% 时 CCR=0，50% 时 CCR=1800，100% 时 CCR=3600，两路可独立调节。
4. A、B 都能独立正转、反转、调速和停止；正负速度定义与车体前后一致。
5. 双路运行后 `Motor_StopAll()` 能关闭输出；HAL 初始化错误路径也不会保留有效 PWM。
6. 低载测试时电源无异常跌落，驱动板、电机和接线无异常发热，开发板不复位、不产生明显控制异常。
7. 本文要求的接线、引脚分配和代码边界均已实现后，才可进入带轮地面测试；编码器闭环不属于本阶段验收项。

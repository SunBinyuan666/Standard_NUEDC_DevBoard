# HC-SR04 舵机扫描避障设计要求

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0.0 |
| 日期 | 2026-11-09 |
| 目标硬件 | Standard NUEDC DevBoard，STM32F103VET6 |
| 传感器 | HC-SR04 超声波测距模块，安装在 SG90 舵机支架上 |
| 控制目标 | 扫描正前方及左右方向，选择可测得的较开阔方向并转动传感器朝向该方向 |
| 设计边界 | 本版本只控制传感器云台方向；未提供底盘电机/转向驱动接口，不会驱动机器人底盘避开障碍 |

---

## 1. 目的与术语

定义基于 STM32CubeMX/HAL 的超声波扫描程序要求。HC-SR04 固定在 SG90 舵机上，由 STM32 产生舵机 PWM、触发测距、测量回波脉宽，并按左/中/右方向的距离数据选择传感器朝向。

本文中的“避障方向”是传感器可朝向的候选方向，不代表机器人车体已经转向或移动。若产品需要主动改变底盘行驶方向，必须另行接入电机驱动、定义停车/转向策略并重新进行安全分析。

## 2. 适用范围和假设

1. 控制板为 Standard NUEDC DevBoard，主控 STM32F103VET6；引脚依据项目中的 `AI_Development/所有元器件的连接方式.md`。
2. 舵机使用此前确定的 TIM3_CH1/PA6 输出 50 Hz PWM。
3. 超声波模块按常见 5 V HC-SR04 接口设计。市场上有不同兼容板，供电、输入阈值和输出电平必须以手中模块资料及实测为准。
4. HC-SR04 常见规格描述为约 2–400 cm 测距，TRIG 高脉冲至少 10 μs，距离由 ECHO 高脉冲宽度表示。此范围不是对所有仿制模块、材料和环境的保证。
5. 单个超声波探头只提供窄角度前向测量，不能保证覆盖两侧、顶部、低矮物体或吸音/倾斜表面。

## 3. 功能需求

### 3.1 基本功能

- 上电后将舵机移至经校准的中位，等待机械稳定，再测量正前方距离。
- 正前方检测到障碍时，依次扫描左、右候选角度；如有需要，重新测量中位，综合三方向距离后作出选择。
- 如果正前方畅通，舵机保持中位，不做无意义的持续左右摆动；按配置周期复测前方。
- 如果正前方受阻，选取测得有效、判定为畅通且更开阔的一侧，舵机停留在该方向；经过保持时间后继续复测，必要时重新扫描。
- 如没有可靠的畅通候选方向，进入“无安全方向/测量异常”状态，按本文件定义的安全策略处理，不得把无回波直接等同于无限远畅通。
- 任何测量、等待舵机稳定、按键处理或状态灯更新不得长时间阻塞主循环；舵机 PWM 由定时器硬件连续产生。

### 3.2 既有三按键的建议用途（可按产品需要关闭）

开发板有 PE13/PE14/PE15 三个低电平有效用户按键。为了便于调试，本设计建议：

| 按键 | 建议功能 |
|---|---|
| SW2 / PE13 | 自动扫描暂停/恢复；暂停时舵机回到校准中位 |
| SW3 / PE14 | 暂停状态下向左手动微调 5° |
| SW4 / PE15 | 暂停状态下向右手动微调 5° |

按键须软件消抖；一次稳定按下只产生一次事件。手动方向调整须受安全角度范围限制。若本版本不需要人工控制，按键功能可以不实现，自动扫描需求不受影响。

## 4. 硬件接口与引脚规划

下表选择未被板载主要外设占用的引脚，并将舵机 PWM 与 Echo 输入捕获放在不同定时器上。

| 功能 | MCU 引脚/定时器 | 开发板引出 | CubeMX 配置 | 说明 |
|---|---|---|---|---|
| SG90 信号 | PA6 / TIM3_CH1 | H2.30 | TIM3 PWM Generation CH1 | 默认映射，不启用 TIM3 重映射 |
| HC-SR04 TRIG | PB0 | H2.34 | GPIO_Output | 输出至少 10 μs 高脉冲 |
| HC-SR04 ECHO | PB9 / TIM4_CH4 | H3.5 | TIM4 Input Capture CH4 | ECHO 经 5 V 到 3.3 V 电平转换后输入 |
| 板载 LED3 | PB6 | H3.8、板载 LED3 | GPIO_Output | 低电平点亮 |
| 板载 LED4 | PB7 | H3.7、板载 LED4 | GPIO_Output | 低电平点亮 |
| 板载 LED5 | PD8 | H3.42、板载 LED5 | GPIO_Output | 低电平点亮 |
| 可选按键 SW2/3/4 | PE13/PE14/PE15 | 板载按键 | GPIO_Input + Pull-up | 按下接地，低电平有效 |

### 4.1 HC-SR04 与 MCU 的电平安全

- 常见 HC-SR04 由 5 V 供电，ECHO 高电平可能接近 5 V；不得未经电平转换直接接入 MCU。
- 建议 ECHO 端采用电阻分压，例如 ECHO 到 MCU 输入间串联 10 kΩ，MCU 输入节点到 GND 接 20 kΩ，5 V 输入时理论节点约为 3.3 V。分压器地必须与 MCU 地连接。也可用合适的 5 V→3.3 V 电平转换器。
- 分压器取值/容差、输入保护及具体模块输出必须按实物确认；不可只因某些 F103 管脚标称耐 5 V 就省略核对。
- STM32 3.3 V TRIG 对常见 TTL 阈值模块通常可用，但兼容板输入阈值可能不同；首次连接先确认模块认可 3.3 V 高电平。若不确定，增加 3.3 V 到 5 V 缓冲器。

### 4.2 供电要求

- SG90 使用符合具体舵机型号要求的独立稳压电源；TowerPro 原厂 SG90 页面给出的工作电压为 4.8 V，并建议通过外部适配器供电。兼容舵机可能参数不同，以实物规格为准。
- HC-SR04 按模块要求供电，常见版本使用 5 V。若与舵机共用电源，电源必须同时满足舵机启动/堵转瞬态和超声波模块的需求，并注意去耦、线径和压降；不得直接把外部正电源并入开发板 5 V。
- 舵机电源负极、HC-SR04 GND 与开发板 GND 必须共地；信号线 PA6、PB0、PB9 按表连接。
- 本开发板 5 V 外设路径经过 U3 自恢复保险丝。项目连接资料记载 U3 为 JK-nSMD005/60V；该型号常见参数资料列出保持电流 50 mA、跳闸电流 150 mA。实际装配料号、温升和板级电源能力未通过实测确认，因此本设计不将板上 H2 5 V 作为舵机电源，也不默认其有充足的传感器余量。
- 不得用 MCU 3.3 V 稳压器或 GPIO 驱动舵机电机。调试时观察舵机动作是否导致 MCU 复位或传感器读数异常。

## 5. STM32CubeMX 配置要求

### 5.1 工程与时钟

1. 选择器件 `STM32F103VETx`，对应板上 STM32F103VET6。
2. RCC HSE 配置为 `Crystal/Ceramic Resonator`；板载 X1 为 8 MHz 无源晶体。
3. PLL 源选 HSE，倍频 ×9；SYSCLK/HCLK=72 MHz，AHB=/1，APB1=/2（PCLK1=36 MHz），APB2=/1（PCLK2=72 MHz）。
4. 确认 APB1 定时器时钟为 72 MHz（APB1 分频非 1 时，F1 定时器时钟为 APB1 时钟的 2 倍）。
5. 选择工程实际使用的 IDE/工具链和 STM32Cube FW_F1 包版本。

### 5.2 TIM3：SG90 PWM

在 `Timers -> TIM3` 中配置：

| 参数 | 配置值 |
|---|---:|
| Clock Source | Internal Clock |
| Channel 1 | PWM Generation CH1 |
| 引脚 | PA6 / TIM3_CH1 |
| Prescaler (PSC) | 71 |
| Counter Period (ARR) | 19999 |
| Pulse/CCR1 初值 | 1500 |
| Counter Mode | Up |
| PWM Mode | PWM mode 1 |
| Polarity | High |
| Clock Division | DIV1 |
| TIM3 中断 | 不启用 |

计数时钟为 72 MHz/(71+1)=1 MHz，即 1 μs/tick；周期为 (19999+1) μs=20 ms，即 50 Hz。比较值单位为约 1 μs。应用初始化后启动 `HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1)`，按目标角度更新 CCR1。

### 5.3 TIM4：ECHO 输入捕获

在 `Timers -> TIM4` 中配置：

| 参数 | 配置值 |
|---|---:|
| Clock Source | Internal Clock |
| Channel 4 | Input Capture direct mode |
| 引脚 | PB9 / TIM4_CH4 默认映射 |
| Prescaler (PSC) | 71 |
| Counter Period (ARR) | 65535 |
| Counter Mode | Up |
| 输入捕获分频 | DIV1 |
| 输入极性初值 | Rising edge |
| Input Filter | 适量数字滤波（从低值开始实测，避免吞掉窄边沿） |
| NVIC | 启用 TIM4 global interrupt |

TIM4 计数分辨率约为 1 μs，16 位计数器约每 65.536 ms 回绕。HC-SR04 常见最远回波脉宽约 23 ms，软件超时建议设为 30 ms，因此有效回波区间小于一次回绕。输入捕获回调应在上升沿记录起点并改为下降沿，在下降沿计算脉宽并恢复上升沿等待；对两个 16 位捕获值使用模 65536 的差值计算。

输入捕获启动后使用 `HAL_TIM_IC_Start_IT(&htim4, TIM_CHANNEL_4)`。若实际 HAL/CubeMX 版本用不同中断处理函数或通道启动接口，按所生成的 `stm32f1xx_it.c` 和 HAL 定义实现，不要手动猜测中断向量名。

### 5.4 GPIO 与中断

- PB0：`GPIO_Output`、Push-Pull、No Pull；初始低电平。
- PB9：由 TIM4_CH4 配置为定时器输入捕获复用功能；外部 ECHO 电平转换器输出接 PB9。
- PB6/PB7/PD8：`GPIO_Output`、Push-Pull、Low speed、No Pull；初始写高以熄灭 LED。
- PE13/PE14/PE15（若实现按键）：`GPIO_Input`、Pull-up；低电平按下，轮询消抖即可，不需要 EXTI。
- 启用 TIM4 全局中断用于捕获边沿；不启用 TIM3 PWM 中断，不启用 DMA。
- TRIG 的 10 μs 脉冲用 DWT 周期计数器或独立硬件单脉冲/精确短时基实现；不要用毫秒粒度的 `HAL_Delay()` 代替微秒延时。

## 6. 测距与扫描算法要求

### 6.1 HC-SR04 单次测距流程

1. 确认距离测量状态为空闲，TRIG 先保持低电平。
2. 输出至少 10 μs 高电平 TRIG 脉冲，然后拉低。
3. 等待 ECHO 上升沿输入捕获，记录起始计数；随后等待下降沿输入捕获，记录结束计数。
4. 计算 `echo_us = (uint16_t)(fall_count - rise_count)`，在 30 ms 内未形成完整脉冲则返回超时/无效状态。
5. 常用近似距离换算为 `distance_cm = echo_us / 58`；若需更细单位，可用 343 m/s 声速近似：`distance_mm = echo_us * 343 / 2000`。换算须使用足够宽的无符号整数，防止乘法溢出。
6. 每次 TRIG 之间至少间隔 60 ms（按常见 HC-SR04 模块建议值）；不得在上一次回波尚未完成时发出下一次触发。
7. 测距结果小于典型最小量程、超出配置最大量程、无回波、ECHO 卡高或输入捕获顺序错误时，应分别标注为“过近”或“无效/未知”，不得伪造正常距离。

### 6.2 单方向滤波

- 每个扫描方向采集 3 次，测量触发间隔不小于 60 ms；取有效样本的中值作为该方向代表距离。
- 有效样本少于 2 个时，该方向标记为未知，不参与“最开阔方向”比较。
- 明显突变值可作为异常样本剔除，但不得无记录地把超时/无回波改成最大距离。
- 舵机换向后至少等待 200 ms（或实测确定的稳定时间）再开始该角度的第一笔测距；舵机在负载下需要更长时间时应增加等待时间。
- 超声波传感器的发射波束宽度、目标表面材质、角度和多径会影响测量；判定阈值必须现场标定。

### 6.3 扫描角度与判定阈值

- 定义 `SERVO_CENTER_DEG`、`SERVO_LEFT_DEG`、`SERVO_RIGHT_DEG` 和允许的最小/最大舵机命令角度为具名配置常量。
- 建议首次验证从中位两侧各 20° 开始，确认安装干涉和方向后，再逐步扩大扫描角度；不得直接将标称 0°/180° 视作安全机械行程。
- 量产/展示时可将左/中/右定义为相对中位约 −40°/0°/+40°，但必须通过实物确认方向、限位及视场。若舵机反向安装，应在配置中交换左右映射。
- 障碍距离阈值由配置常量控制。建议初始参数：障碍阈值 25 cm、明确畅通阈值 35 cm，中间 25–35 cm 为谨慎区；具体数值按底盘速度、制动距离和场地重新确定。
- 滞回规则：进入障碍状态采用较低阈值，恢复畅通采用较高阈值；新方向落在谨慎区时不得轻易判作安全通道。
- 有效左、右候选均畅通时，选取距离较大的方向；距离差小于配置切换裕量（建议 10 cm）时优先保持上一已选方向，减少舵机来回抖动。
- 如果中位畅通，优先回到中位。只有中位受阻时才选择左右侧，除非产品策略另有定义。

### 6.4 方向选择与异常策略

| 情况 | 要求的处理 |
|---|---|
| 中位有效且畅通 | 舵机保持中位，进入前方监测状态 |
| 中位受阻，左侧畅通、右侧受阻/未知 | 舵机指向左侧有效畅通方向 |
| 中位受阻，右侧畅通、左侧受阻/未知 | 舵机指向右侧有效畅通方向 |
| 中位受阻，左右均畅通 | 选择代表距离较大的一侧；差值很小时保持此前方向 |
| 中位未知/超时，至少一侧有有效畅通读数 | 不得将中位记为畅通；可指向有效畅通侧，同时置测量降级状态并尽快重测中位 |
| 中位及左右均受阻，或左右均无有效读数 | 标记无安全方向/传感器异常；云台回中或保持已定义的观察角度并报警。若未来接入底盘驱动，必须同时发出停车命令 |
| 所有方向均无效/传感器连续超时 | 标记传感器异常；不把未知当畅通，LED5 快速闪烁并在安全角度等待重试 |
| 距离处于阈值滞回区 | 保持谨慎状态；继续采样，不进行频繁左右切换 |

“保持已定义观察角度”不得被误解为机器人可以继续行驶。没有底盘电机和停车接口时，本工程只能报告云台当前指向和测距状态。

### 6.5 建议状态机

```text
INIT
  -> CENTER_SETTLE
  -> CENTER_MEASURE
       ├─ 中位畅通 -> FORWARD_HOLD -> 定期复测 CENTER_MEASURE
       └─ 中位受阻/未知 -> MOVE_LEFT -> LEFT_SETTLE -> LEFT_MEASURE
          -> MOVE_RIGHT -> RIGHT_SETTLE -> RIGHT_MEASURE -> SELECT_DIRECTION
              ├─ 有有效畅通方向 -> POINT_TO_SELECTED -> DIRECTION_HOLD -> 重新评估
              └─ 无有效畅通方向 -> NO_CLEAR_OR_SENSOR_FAULT -> 延时重试

任一状态发生暂停按键（若启用） -> PAUSED_CENTER
```

每个状态需要有进入时间、超时、成功/失败转移和可观测状态。禁止在状态转移中使用长时间阻塞延时。

## 7. 舵机控制要求

- PWM 参数：TIM3_CH1/PA6，50 Hz，PSC=71、ARR=19999，在 72 MHz TIM3 时钟下 1 tick 约 1 μs。
- 上电先输出校准中位命令，建议从约 1500 μs 开始；此值是初始命令，不保证每只 SG90 的几何中位完全一致。
- 脉宽使用 `SERVO_MIN_PULSE_US`、`SERVO_CENTER_PULSE_US` 和 `SERVO_MAX_PULSE_US` 配置；初次实测可先用 1000–2000 μs 的保守窗口，再按具体舵机逐步校准，不允许持续顶机械止点。
- 角度到脉宽的映射应采用限幅后的线性或标定表换算；限制 CCR 不得超出定时器周期，并确保 CCR=0/ARR 周边行为经过验证。
- 当舵机角度改变时，只更新 CCR，不重新初始化整个 TIM3，不停止并重启 PWM。
- 舵机供电异常、过热、异响、机械卡住或电源压降时，应立即断电检查，不得用软件扩大行程强行克服机械阻力。

## 8. 状态灯和可选按键

### 8.1 LED 建议编码

板载 LED3/PB6、LED4/PB7、LED5/PD8 均为低电平点亮。

| 状态 | LED3/PB6 | LED4/PB7 | LED5/PD8 |
|---|---|---|---|
| 正常监测/中位畅通 | 熄灭 | 熄灭 | 慢速心跳（约 1 Hz 翻转） |
| 已选左侧 | 亮 | 灭 | 慢速心跳 |
| 已选右侧 | 灭 | 亮 | 慢速心跳 |
| 正在扫描 | 随当前待测方向提示 | 随当前待测方向提示 | 约 2 Hz 闪烁 |
| 无安全方向 | 左/右灯均灭 | 左/右灯均灭 | 约 4 Hz 闪烁 |
| 传感器故障/连续超时 | 左/右灯均灭 | 左/右灯均灭 | 约 4 Hz 闪烁，并可由软件区分错误码 |
| 人工暂停（若启用） | 按当前人工指向显示 | 按当前人工指向显示 | 常亮或慢闪，需在代码注释中固定定义 |

状态灯时序使用 `HAL_GetTick()` 等毫秒节拍调度，不得通过阻塞延时驱动。

### 8.2 按键消抖（若启用）

- PE13/PE14/PE15 输入上拉，按下为低电平。
- 连续稳定 20 ms 后确认状态改变。
- 一次按下只触发一次操作；必须释放后才允许下一次。
- 暂停期间手动左右角度调节仍受校准机械限位约束。

## 9. 软件质量要求

- 建议模块拆分：`app_servo`、`app_hcsr04`、`app_obstacle_scan`、`app_led`、可选 `app_button`。
- ISR/回调只记录捕获值、更新测量阶段标志或置事件；距离滤波、方向决策、LED 更新在主循环状态机中完成。
- 所有测量状态、目标角度、超时和无效原因有清晰枚举/标志；避免用魔法数字。
- 时间差计算必须处理定时器回绕；定时器和 HAL tick 的时钟关系变化时需重新验证。
- 不在头文件中定义全局对象；应用私有变量使用 `static`，关键共享标志按中断并发需要使用 `volatile` 或临界区保护。
- CubeMX 自动生成代码保持在生成区；应用逻辑放入独立源文件或 `USER CODE` 区域，避免重新生成时丢失。
- 命名、固定宽度整数类型、函数长度和格式遵循 `AI_Development/个人编程代码规范.md`。

## 11. 风险与限制

- HC-SR04 为单波束超声测距器，不是完整空间感知器。它可能漏检软质、细小、斜置、低矮或处于波束外的障碍物，也会受环境噪声、多径和温度影响。
- SG90 没有向 MCU 提供实际角度反馈；程序能控制目标脉宽，但无法仅凭 PWM 证实舵机真的转到了该角度。
- “距离更大”不一定表示底盘能够通过；没有宽度、侧向净空、运动方向和制动距离信息时，不得将测距结果直接作为安全通行保证。
- 若软件、传感器或电源发生故障，本版本只能通过状态灯提示；若连接底盘，必须增加独立停车策略及可验证的硬件急停，不能只靠 SG90 转头。
- 若用于人员附近、公共道路、自动运行或其他安全相关场景，单个 HC-SR04+SG90 方案不足以承担唯一防碰撞功能，应增加冗余传感器、限速/急停和系统级风险评估。

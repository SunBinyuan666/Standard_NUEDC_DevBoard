### 1.1 阅读约定

1. `U5.23` 表示 U5 的物理引脚 23；`USB1.A6` 表示 Type-C A 面的 A6 焊脚。
2. 同一网络内的端点是直接电气相连；跨电阻、电容、二极管、晶体管、开关或电感的两端不是同一网络。
3. `$1N.../$2N.../$3N...` 是 TEL 自动生成的匿名网络名，本文保留原名并添加语义解释，方便回查。
4. `NC` 表示 PDF 中标 × 或明确不连接，不代表逻辑低或电源地。开关未使用触点保留符号标签，不猜测 PDF 没显示的物理脚号。
5. 每个元器件都有引脚表；普通小网络直接列出其他端点，大型公用网络通过附录列出全部端点。表中“同网其他端点”不包括该行自身。
6. 接口的 PCB 针号不等同于图片左右方向、软件端口编号或开关机械档位。

## 2. 板级连接总览

### 2.1 电源结构

```text
CN1.1 / DC1.4
  → D1（SS54）
  → U1 VIN + C1/C2/C3 输入滤波
  → U1 PH + D2 续流 + L1（15µH）
  → 公共前级5V（PDF DC+5V 与 USB+5V 同网；TEL 统一为 USB+5V）
      ├─ USB1/USB2 的全部 VBUS
      ├─ C5/C6/C7 与 LED2/R6
      └─ U2 开关 → U3 保险丝 → VCC+5V
          ├─ 外设接口 P1/P2/P3/U11/U12、H2 的5V针
          └─ U4 AMS1117-3.3 → VCC+3.3V
              ├─ MCU 数字电源、CH340C、LED与上拉
              ├─ R7（0Ω）→ VCCA+3.3V → MCU VDDA
              │    └─ R9（1kΩ）→ U6 TL431 + C19 → MCU VREF+
              └─ D3一路阳极 → 共阴极VBAT
BT1正极 → D3另一路阳极 → 共阴极VBAT → U5.6
GND ← R8（0Ω）→ AGND
```

这里的“5V/3.3V”是网络名和设计意图，不是已测电压。特别是 USB 两口与 DC/DC 输出在开关之前已共网，U2/U3 不提供三路输入相互隔离。

### 2.2 主控最小系统

- 数字 VDD：U5.11/28/50/75/100 接 3.3V；VSS：U5.10/27/49/74/99 接 GND；C13–C17 去耦。
- VDDA=U5.22 接模拟 3.3V；VSSA=U5.19 与 VREF−=U5.20 接 AGND；VREF+=U5.21 接 TL431 参考节点。
- VBAT=U5.6 由 D3 合并数字 3.3V/电池，C18 到地。
- 高速晶体 X1：8MHz，连接 U5.12/13，C20/C21 各 20pF 到地；低速晶体 X2：32.768kHz，连接 U5.8/9，C22/C23 各 10pF 到地。
- RST=U5.14：R10 10kΩ 上拉、C24 100nF 到地、SW1 按下接地，并与 U14 相连。
- H1 通过 R11/R12 选择 BOOT1/BOOT0；PB2 就是 U5.37 的 BOOT1 同节点，未另外单独引出 PB2 网络。

### 2.3 接口及 GPIO 分配

| 模块 | 元器件 | MCU 信号 | 硬件连接要点 |
|---|---|---|---|
| USB 转 UART | USB1、U13 | PA9=MCU TX、PA10=MCU RX | CH340C RXD 接 PA9，TXD 接 PA10；默认 USART1 布局 |

| 自动下载 | Q1/Q2/U14/R27–R30 | RST、BOOT0 | 控制来自 CH340C DTR#/RTS# |
| SWD | H4 | PA13、PA14 | 1=3.3V，4=GND，无 NRST 针 |
| 模拟输入 | U7/U8 | PA0、PA1 | 中心端直连，外壳接 AGND |
| 模拟输出 | U9/U10 | PA4、PA5 | 图中 DAC 接口，中心端直连 |
| UART3/可选上拉 | P1/SW5/R21/R22 | PB10、PB11 | USART3 默认布局，也可按功能作 I²C2 |
| UART2/可选上拉 | P2/SW6/R25/R26 | PA2、PA3 | USART2 默认布局；若作 I²C 要另核功能/软件实现 |
| UART4/可选上拉 | P3/SW7/R23/R24 | PC10、PC11 | UART4 布局；与其他可复用外设共用引脚 |
| SPI | U11 | PA15/PB3/PB4/PB5 | 图中分别 CS/CLK/MISO/MOSI，SPI1 重映射与 JTAG 复用需配置 |

| 用户按键 | SW2/SW3/SW4 | PE13/PE14/PE15 | 按下到地，分别 C25/C26/C27 到地，未见外部上拉 |
| 用户 LED | LED3/LED4/LED5 | PB6/PB7/PD8 | 2kΩ 从3.3V供电，GPIO低电平点亮 |
| GPIO 扩展 | H2/H3 | 见逐针表 | 与板载接口共网，不是另一个独立GPIO副本 |

## 5. 原理图与网表差异、使用限制及待核对项

### 5.1 已确认的差异和补充

1. **型号缺失由 PDF 补齐**：TEL 里多个器件只导出 `{Value}`；PDF 明确了 STM32F103VET6、TPS5450QDDARQ1、AMS1117-3.3、TL431QDBZR、CH340C、S8050/S8550、BAT54C、SS54、1N4007W 及保险丝/连接器型号。
2. **DC+5V 与 USB+5V 已合并**：PDF 的电源合路图上有明确导线连接两个标签；TEL 统一为 USB+5V，不是本文漏了一条独立 DC 电源。
3. **接口别名已归一**：PDF 的 USBN/USBP、TXD/RXD、SCL/SDA、SPI、SWD 标签在 TEL 中多以 GPIO 网络名出现，详见 §2.4。
4. **未连接脚不等于缺失元器件**：U1.2/3/5、U5.73、U13.7/8/9/10/11/12/15、USB1/2.A8/B8 在 PDF 中未连接，本文单列 NC。SW5–SW7 的 A/B 触点也未连接，但不臆造编号。
5. **辅助焊盘不是多出来的接口信号**：PDF 的 P1–P3 符号确实还有 5/6 接地端，U11/U12 有 7/8 接地端；它们对应额外辅助焊盘，功能口仍分别为四针与六针。实际机械焊盘形状仍须对照 PCB 封装。
6. **晶体与 LED 的名称不能只看 TEL 封装**：X1 原理图为无源晶体，但 TEL 封装名包含 SIT8008BI；LED1/2 PDF 型号为 GL0603UG01（绿色），TEL 封装名含 RD。按图识别类型/颜色，生产前再核对实装物料。
7. **本说明没有发现需要把某条已连接 TEL 端点改接别网的证据**；这只表示当前三页可见连接与所用网表可解释地对应，不代表通过完整电气审查或证明两文件导出时刻完全一致。

### 5.2 上电和开发前重点核对

- **多路5V回灌**：USB1/USB2 VBUS 与降压输出处在同一前级5V网络。不要把“电源合路”误读为有防反灌/自动择源电路；D1 仅在 DC 输入侧。是否允许同时接电脑 USB、第二个 USB 或外部 DC，应结合芯片内部反向电流特性、主机保护和实板确认。
- **USB D+ 上拉实为10kΩ**：R15 两份来源都为10kΩ。需按 STM32F103 USB FS 外部上拉要求核对该值、识别可靠性以及断电时供电路径；本文未替用户把它改成其他阻值。
- **参考电压电路不等同于“模拟3.3V”**：U5 VDDA 与 VREF+ 是不同网络。TL431 CAT/REF 短接、R9=1kΩ、C19=10µF 时需验证工作电流余量、输出稳定性和有效参考电压；ADC/DAC 代码不能未经实测把 VREF+ 固定假定成3.3V。
- **BOOT偏置与自动下载**：BOOT1 的静态偏置取决于 H1 跳帽；BOOT0 还受 Q2 控制，未见独立固定下拉。下载结束、控制线释放、跳帽未装时的状态必须测试。DTR/RTS 标签对应的是 CH340C 带 # 的输出，需要核对软件极性与时序。
- **U2机械档位**：图中接地触点和短接输出触点必须按 YSSP2AG00 实际接触结构理解；静态网表不能证明某档不会造成前级5V短接地或明确 ON/OFF 位置。本文不生成未经物料图验证的机械真值表。
- **外设供电与逻辑电平**：P1/P2/P3/U11/U12 提供5V，但信号线直接接3.3V MCU；并非全部信号都能耐受5V，模拟脚尤其需要按 MCU 规格核对。图中未见统一电平转换、模拟缓冲或限流保护。
- **复用冲突**：PB6/PB7/PD8 挂有用户LED；PE13/14/15 挂有按键及电容；PA11/12 挂USB；PA9/10 挂CH340C；PA13/14 挂SWD；PA15/PB3/PB4 挂SPI/JTAG复用。虽然都从 H2/H3 引出，使用时仍要考虑这些板载负载。
- **“串口/IIC切换”只切换上拉**：三个开关没有把信号换接到其他MCU口。PB10/PB11 的硬件 I²C 能力、其他引脚的软件实现和具体重映射需各自配置，不是拨开关就自动切换外设协议。
- **“6路IIC”不意味着6路硬件I²C**：U12 是六功能端子的连接器，PB15/PB14 有两只上拉；其余两GPIO没有此上拉。须按图与固件约定识别。
- **器件规格仍未全给出**：PDF 没标所有电容耐压、电阻功率、电感饱和电流、允许DC输入范围、晶体完整料号及保险丝动作参数。这里的连接说明不补造这些规格。
